What is this?

The link holds the codes for a set time, worked out ahead by Keyrook Authenticator on the sender’s computer — never the key that makes them. When that time is over there is nothing left in it to show, on this device or any other.

This page cannot send the codes anywhere. Its Content Security Policy forbids it to load or send anything, and to run any script but its own; and the part of the link that holds them, after the #, is never sent to a server. Anyone who has the link can see the codes until it ends, so keep it to yourself.
